Key Capabilities
📡

Multi-Layer Protocol Analysis

Parses all 3GPP radio stack layers from a single log file.

  • NAS — TS 24.301 (LTE) / 24.501 (NR)
  • RRC — TS 36.331 (LTE) / 38.331 (NR)
  • PHY — RSRP, RSRQ, SINR, CQI, MCS, BLER
⚡

Real-time Event Stream

Processes entries as they are read — no need to load the entire file into memory. Handles 100MB+ logs.

📉

KPI Dashboard

Automatically computes Attach Success Rate, Handover Success Rate, Avg RSRP/RSRQ/SINR, setup times, RLF rate.

🔮

Anomaly Detection

7 sliding-window rules fire automatically: repeated failures, auth loops, ping-pong HO, RLF clusters, signaling storms.

📋

Cause Code Decoder

Full EMM, 5GMM, ESM, and 5GSM cause code lookup tables mapped to human-readable descriptions from the spec.

🗺️

Message Sequence Chart

Renders a 3GPP-style ladder diagram (UE ↔ eNB/gNB ↔ MME/AMF ↔ SGW/UPF) with failure arrows highlighted in red.

Anomaly Detection Rules Engine

7 sliding-window rules run automatically after every load. Rules are configurable in config/anomaly_rules.yaml.

RuleTrigger ConditionWindowSeverityWhy It Matters
Repeated Attach Failures ≥ 3 Attach / Registration Failures 5 min ERROR SIM rejected, PLMN barred, or network congestion loop
Authentication Loop ≥ 3 Authentication Failures 2 min ERROR AKA vector mismatch, SIM issue, or MITM attack
Ping-Pong Handover ≥ 3 HOs between same 2 PCIs 2 min WARNING A3/A5 event thresholds too aggressive, coverage hole
RLF Cluster ≥ 2 Radio Link Failures 5 min ERROR Coverage gap, interference, or hardware fault
Signaling Storm > 50 signaling events 10 s WARNING Stuck state machine, retry loop, or test harness issue
Short-lived Bearer Bearer active < 2 s then deactivated — WARNING Misconfigured APN, quota exceeded, or SGW reject
Timer Expiry NAS timer expiry keyword in log — ERROR T3410 / T3411 / T3402 — attach procedure stuck
